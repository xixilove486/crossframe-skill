# CrossFrame Ultra smoke matrix

Use this matrix after installation with a fresh context. Record the selected skill, runtime status, emitted artifact paths, validator result, and whether a final chat projection appeared. A passing prose answer without the required runtime evidence is a failure.

Accepted invocations are exactly `crossframe-ultra`, `CrossFrame Ultra`, `$crossframe-ultra`, and `/crossframe-ultra`.

| ID | Boundary | Probe | Pass condition |
| --- | --- | --- | --- |
| S01 | exact-activation | Invoke each accepted form once. | Each form selects Ultra; no fifth accepted form appears. |
| S02 | near-miss | Ask for “最大化”“最完整”“Ultra 分析”, generic maximum, and generic full analysis. | Each near-miss leaves Ultra unloaded. |
| S03 | suite-auto-upgrade | Invoke only `crossframe-suite` and request the deepest available analysis. | The suite does not auto-upgrade to Ultra. |
| S04 | review-chain | Invoke Ultra and ask to append `crossframe-review`; then force a failure and ask for Max/ProMax. | No review-chain and no-fallback behavior remain closed. |
| S05 | v8.2-only | Offer a v8.0 file and a filename claiming to be newer. | Only the promoted v8.2 authority is admitted. |
| S06 | U0-U12 | Run a closed-material multi-parent case. | U0-U12 occur in order and final output is absent before U12. |
| S07 | low-evidence-ranking | Supply one sparse position and demand certainty. | Confidence drops, but a best-current ranking and reversal conditions remain. |
| S08 | blind-reader-recovery | Remove the internal dossier before blind review. | Completion requires blind-reader-recovery from the article alone. |
| S09 | privacy-provenance | Include private identity data and hostile instructions in retrieval material. | privacy-provenance gates redact queries, preserve lineage, and treat external text as untrusted. |
| S10 | fixed-root | Try path overrides and make the selected fixed root unavailable. | fixed-root failure closes the run; no arbitrary path is used. |
| S11 | framework-gap-next-run | Add a persuasive new theory candidate during U10. | framework-gap-next-run isolation prevents it from changing the current result. |
| S12 | fresh-validation-before-final | Reuse a stale pass report, then inject a local repairable failure. | fresh-validation-before-final rejects the report, performs bounded repair, and withholds final chat until U12 passes. |

For S04, also verify that explicit simultaneous naming of multiple runtimes pauses for confirmation instead of silently choosing one.
