本模板用于 U10 隔离 framework gap 候选。单次运行可以发现缺口，但不得把候选写回 v8.2 权威快照或冒充新理论。

| gap | description | evidence / claim / mechanism | framework boundary | disposition |
|---|---|---|---|---|

## boundary

区分材料 unknown、当前不可识别、能力限制与真正的 framework boundary。只有现有 route、contract 和 concept 均无法表达且有可追溯证据时，才登记 gap 候选。

## disposition

disposition 说明保留、拒绝或延后理由，以及未来 revision proposal。任何处置都不得改变本运行冻结的版本绑定。
