# CrossFrame ProMax Rule

CrossFrame ProMax is a v8-only, exact-name only independent skill.

Activate only when the user writes `crossframe-promax`, `CrossFrame ProMax`, `$crossframe-promax`, or `/crossframe-promax`. Read `skills/crossframe-promax/SKILL.md` and follow its production artifact runtime.

If both Max and ProMax are named, ProMax wins. Routing invariant: generic maximality remains Max; suite never auto-upgrades to ProMax. ProMax uses its own audit, has no review chain, and never falls back to Max.
