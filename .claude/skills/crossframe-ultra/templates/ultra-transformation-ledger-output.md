# Ultra 变换台账输出

本模板用于 U5 分开记录尺度变换、圈层关系变换与表示转义。每条记录必须绑定来源、目标和证据，不得用一种变换替代另一种。

## transformation rule

| 变换标识 | 类型 | source | target | rule | 闭合状态 |
|---|---|---|---|---|---|
| 待填 | scale / circle-relation / representation | 待填 | 待填 | 待填 | 待填 |

## effect

逐位置说明 effect：哪些变量保留、改变、扩张、收缩或不可比较，以及收益、损害、退出成本和外溢落在哪里。

## provenance

provenance 必须列出 evidence 引用、输入与输出身份、验证见证和散列。缺失见证时应保留 unknown、information loss、residual 与回返条件，不得伪称等价或有序。
